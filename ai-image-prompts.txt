SquareCampus — AI image generation prompts
===========================================
One prompt per asset we plan to replace. Each entry lists the file it replaces,
where it is used, the required format, and the prompt to paste into your image
model. Keep the exact aspect ratios — the layout depends on them.

Global style notes (append to every prompt if your tool supports a style field):
"Clean, premium SaaS aesthetic. Soft neutral background tones (warm off-white
#F6F6F3 in light contexts). Subtle cool-blue accent lighting (#587CCC family).
No text, no logos, no watermarks, no people's identifiable faces. Crisp edges,
high resolution, photorealistic product-render quality."

1. MacBook device frame (replaces public/images/devices/macbook-air-figma.webp)
-------------------------------------------------------------------------------
Used in: LaptopFrame in src/components/site/mockups.tsx — hero, platform,
ecosystem, rollout, and security mockups. The screen area must stay EMPTY
(transparent) because live HTML UI renders behind the cutout.
Format: PNG with transparent background AND transparent screen cutout,
aspect ratio 3880:2300, front-facing, minimum 2400px wide.

Prompt:
"A photorealistic front view of a modern ultra-thin laptop (similar to a
MacBook Air), perfectly centered and symmetrical, lid open at 100 degrees,
viewed straight-on at screen height. Silver-grey aluminum body, minimal bezel,
no keyboard visible beyond the base edge. The screen area is fully transparent
(cut out) so interface content can be composited behind it. Transparent
background. Studio product-render lighting with a soft cool-blue rim light.
No logo on the lid, no reflections that obscure the screen cutout, no text."

2. Smartphone device frame (replaces public/images/devices/iphone-13-silver-portrait.webp)
-------------------------------------------------------------------------------
Used in: FigmaIphoneFrame in src/components/site/mockups.tsx — parent/student
app mockups beside the laptop. Screen must be a transparent cutout; the app UI

"A photorealistic front view of a modern flagship smartphone in silver/starlight

area is fully transparent (cut out) so app interface content can be composited

cool-blue edge highlight. No logos, no buttons pressed, no text, no reflections
covering the screen cutout."

Tips
----
- For the two device frames (1 and 2), if your model can't produce transparent
  screen cutouts reliably, generate the device on a solid #00FF00 screen and
  background, then key both out in an editor. The screen rectangle must be
  perfectly straight-on (no perspective) or the composited UI will not align.
- Keep the same filenames when replacing so no code changes are needed.
- After replacing, run `bun run build` and eyeball /, /platform, /ecosystem,
  /rollout, /security, and /school-management-system.
