# Security Policy

## Reporting a Vulnerability
If you believe you have found a security issue, please report it privately.

- Email: security@squarecampus.com
- Please include a clear description, steps to reproduce, and potential impact.

## Disclosure Policy
- We will acknowledge receipt within 3 business days.
- We will provide a timeline for investigation and remediation.
- Please avoid public disclosure until we have resolved the issue.
